# Llama 3.1-8B / source15：完整 32 Block GPU 执行结果

## 结论与模型边界

真实权重、32 个 Decoder Block 已在单卡 A800 80 GB 完成连续 CKKS 密文计算，退出码为 0，全部最终槽位输出有限。容量 128 token，本次输入 38 个有效 token。输入是加密 embedding，模型输出是最后一个 Block 的密文 hidden；验收驱动器仅在全部 Block 完成后解密。没有中途解密反馈，也没有用明文或 Mock 代替子层。

本次按用户要求验收“能完整运行并得到结果”，精度单独记录。`precision_passed=False`，不能将执行成功解释为精度达标。此 benchmark 不包含 tokenizer、最终 RMSNorm、LM head 或增量 decode。

参考是既有 Cerium original_callpath_v2 的 float64 近似 packed 运算，含固定 jitter；它不是标准 Hugging Face 精确算子结果，也不是当前 C++ 每条指令的浮点重放。因此最终差异同时可能包含参考路径差别和 CKKS 误差，本次不能据此单独归因于某个自举或算子。阈值 1e-3 仅作为报告字段保留，不影响本次执行验收。

## 来源与必要适配

固定 Cerium commit：6b487041f69bcd04fb2138b8be87635ddeb128d6。后端为 FHE_GPU_Agent 的 ResNet20 GPU API，基础版本 55e51804。source15 与 source13 的 C++/hpp 逐文件哈希一致。本次使用已有四个真实权重分片，启动时核验尺寸；分片 SHA256 已在下载阶段校验，本次没有宣称重新计算了全部约 16 GB 权重的哈希。

保留原公式、系数、显式自举位置、packed 布局及全部 QK→全部 Softmax→全部 AV 顺序。未移植原双 lane 自举、全图调度器与 CUDA Graph；native DFT 每输入 tile rescale、有限常量缓存与逐层流式权重属于接口/资源适配。详见 SOURCE_MAPPING.md，不能称为原运行时逐项完全相同。
