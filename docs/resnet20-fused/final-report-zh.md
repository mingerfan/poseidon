设备 Tesla V100-SXM2-32GB、CUDA 12.2，图像 0。以下均为单次在线测量，不是多轮中位数：

融合版本的计时包含部分 CPU 矩阵准备和调度，算法、版本及计时范围与基线不同，不能将以上数字当作严格同口径加速比；也不能把这些历史结果当作最新 A800 优化代码在 V100 上的结果。V100 上 D15/D31 的完整网络、宽模数 NTT、ModRaise、BV 及 StC/CtS 组件检查通过；融合单组件最大槽误差分别为 3.48168e-7 和 4.11494e-7。详细命令、参数、版本和原始日志索引见 [V100 原始记录](v100-history.md) 与 `v100-baseline-evidence/`。

## 迁移与优化方法

1. 使用 Trident 冻结拟合，将非线性计算与自举结合；D15 为 N=32768、Q19/P1，D31 为 N=32768、Q20/P1。整网使用 19 个融合激活点，输出最终 L2。源码执行顺序为 StC、ModRaise、CtS、实部投影、carrier、平方、harmonic 和输出投影，网络层穿插其中。
2. 针对原参数使用宽模数 GPU RNS/NTT、BV 密钥切换、旋转和共轭；卷积与 BN 折叠，并使用 GPU 对角矩阵及 BSGS 完成线性变换。
3. 使用稳定明文索引和预热后的常驻重放，减少在线上传；V100 早期版本已有单次验证。后续 A800 独立副本继续加入共享分解、旋转密钥预变换缓存、内存池、NTT kernel 合并和快速 ModRaise。共享分解路径的密文残基不要求与原路径逐字一致，以解密误差及模型输出回归验收。
4. A800 实验中 NTT tile=2048 相对 1024 的两次 GPU 活动时间为约 4.600/4.602 s 对 3.748/3.749 s，未获收益，保留 1024。快速 ModRaise 的既有开关对照显示收益；这些是 A800 数据，不能写成 V100 或 H100 性能。

具体开关、逐项 A/B、源码哈希和原始日志见 [A800 后续审计报告](a800-audit.md)。

## 最新 A800 验证及瓶颈

最新 D31 在 A800 上完成 1000 张密文推理：GPU 与冻结 D31 明文预测一致 1000/1000，最大 logit 误差 0.0002190412116。D31 对标签正确 904/1000（90.4%），精确 ReLU 明文对标签正确 914/1000（91.4%）；D31 与精确 ReLU 预测一致 959/1000。不得将计算一致率称为模型准确率。

A800 图像 0 冻结基线在线墙钟中位数 2.954 s（3 次），最新 D31 1024 粒度为 4.235 s（2 次）。一次 GPU 追踪中 CtS 旋转及共享准备 1.357 s、carrier 0.816 s、harmonic 0.409 s；两条路径的激活算法和部分 CPU 准备不同。Nsight Compute 硬件计数器权限受限，无法给出可信的硬件带宽、占用率或逐阶段显存峰值。

## 安全与 H100

当前状态 **SECURITY_NOT_VALIDATED**。对实际 QP、CBD(21)、H=32 的条件化 16 正/16 负普通 LWE 示意模型，固定版本 lattice-estimator 的默认 MATZOV 模型给出最低所测攻击成本约 2^118.4。该模型未完整覆盖实际环样本及评估密钥相关性，不是完整系统安全认证；当前参数不得宣称达到 128 位安全。

目前没有可用 H100 实机或实测结果。最新源码已经在 A800 交叉编译 `sm_90` 并检查 cubin；本地提供 H100 构建和多轮测试脚本，**脚本可准备未来测试，但现在不能直接产生真实 H100 测量**。设备、显存、正确性及性能必须在获得 H100 后实测。详见 [重建与测试说明](build-and-run.md) 和 [H100 测试脚本](../../scripts/resnet20-fused/h100-benchmark.sh)。
