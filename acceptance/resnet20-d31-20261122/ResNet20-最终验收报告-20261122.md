## A800 同二进制对照与优化

OPT-016 在 OPT-012 基础上切换 OPT-014 的 NTT 输出与密钥乘加融合，其余配置一致：

| 指标 | OPT-014 关闭 | OPT-014 开启 |
|---|---:|---:|
| 在线墙钟中位数 | 3188.039 ms | 3071.213 ms |
| 墙钟范围 | 3160.641–3204.982 ms | 3070.942–3089.997 ms |
| GPU 活动并集中位数 | 2877.005 ms | 2812.567 ms |
| CtS 旋转中位数 | 1010.368 ms | 999.409 ms |
| kernel 启动数 | 252115 | 226849 |
| 全卡显存采样峰值 | 46509 MiB | 46509 MiB |

五轮两组图像 0 均通过，GPU 在线主机传输为零。墙钟、GPU 活动与 CtS 分项存在包含或重叠关系，不应相加。显存数字是周期采样的全卡值，包含 CUDA 上下文及内存池，并非精确的逐算子峰值。启动密钥生成、模型与公开材料准备不包含在此在线数字中；融合与原 GPU 基线的部分 CPU 准备及算法路径不同。

保留的主要方法包括共享分解与旋转密钥缓存、快速模数提升、OPT-002 共享 digit 密钥乘加、OPT-007 正向 NTT 双级融合、OPT-008 逆向 NTT 双级融合、OPT-010 正向 NTT 三级融合、OPT-012 逆向 NTT 三级融合和 OPT-014 最后一级正向 NTT 与密钥乘加融合。OPT-014 用同输入和密钥检查 Q/P 21 个模数的 1376256 个中间残基，全部与独立计算一致。各优化均保留开关与原路径；需在运行时显式启用选中组合。

无稳定端到端收益的 OPT-003–006、OPT-009、OPT-011、OPT-013、OPT-017 和 OPT-018 均未纳入最终组合。OPT-013 的 CUDA racecheck 为 0 errors、0 warnings，但墙钟区间重叠；OPT-017/018 证明减少 kernel 数不必然提高速度。OPT-015 因先决候选未保留而跳过。OPT-019 在用户要求结束时仅完成部分 A/B，未验收；OPT-020 和 OPT-021 仅准备或排队，未执行 GPU 测试。它们的未完成日志和候选源码保存在 `user-stop-evidence-20261122.tar.gz`，不属于最终版本。

## 复现与交付

`opt-016-source.bundle` 是完整 Git 源码包，SHA-256 `0b65a73d2ea485476db0c9e949bcda8d1e0c17c883a36cfc26adaa9d15b8e37f`；本地 SHA 校验和 `git bundle verify` 均通过，包含完整历史与上述提交。可在 Linux 上以独立目录恢复：

```bash
mkdir poseidon-opt016 && cd poseidon-opt016
git init
git fetch /path/to/opt-016-source.bundle HEAD
git switch -c work/resnet20-fused-d31-opt016 FETCH_HEAD
```

Linux 环境应保留源码中的符号链接，配置 CUDA、GMP、spdlog 等依赖。已验证的 A800 构建命令、环境变量和运行参数见 `opt-016-evidence.tar.gz` 中的 `opt016-input/phase3-opt016.sh` 与 `phase3-opt016-correctness.sh`；路径是当时 A800 的实际路径，迁移机器时需替换。使用现成构建运行 D31 图像 0 的关键参数如下：


## H100 与安全状态

OPT-016 的 `sm_90` 整网、NTT 和 BV 目标已在 A800 主机交叉编译，`cuobjdump` 显示 `sm_90` cubin；可执行文件 SHA-256 `d1ad866c4e1d4713e75556f4b39743717a92370478b3f37e537f3cbcb71a8ccb`。H100 实机不可用，尚无 H100 正确性、显存或性能结果。`h100-test.sh` 支持 `base`/`best` 两种模式，连同 `h100-selected-flags.env` 使用；跨机器应以本机依赖重新构建，详见 `H100-复测说明.md`。构建证据为 `h100-opt016-build-evidence.tar.gz`。

密码学状态为 **SECURITY_NOT_VALIDATED**，不得宣称达到 128 位安全。实际 Q 标称约 880 bit、QP 约 931 bit，P 为 51 bit；既有条件化稀疏密钥普通 LWE 示意估算在所测模型下低于 2^128，且未完整覆盖环样本和评估密钥相关性。具体模型与限制见 `d31-audit-20261118/progress.md`；部署前需要独立安全评审和必要的参数重新设计。
