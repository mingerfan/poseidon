# 输出共享的自动布局接线

自动布局规划已按 `exact-values-v1` 的物理输出数筛选周期。四个名称引用同一个 20 元素结果时，period=4 只需要 5 个输出块；原规划器按 20 个块计算，会遗漏这一候选。

改动位于 `application_planning/layout.py`。只按已选择策略下的同一图值去重；逻辑元素、输出名称、不同图值和明确指定的周期继续按原规则检查。固定请求的编译／执行／验证 SDK 身份保持，布局规划源码闭包与决策绑定更新。

- 67 项规划、资源、输出绑定及旧行为检查通过；12 份旧候选清单逐字保持。

冻结门限保持 `abs(actual-reference) <= 1e-5 + 1e-4*abs(reference)`。

## 使用

`plan_model(model, options=...)` 沿用原接口，在 `options` 中选择：

```python
{
    "output_binding_policy": "exact-values-v1",
    "generation_guidance": "explicit-v15"
}
```

规划成功后，`check_plan()` 复核固定模型、候选和决策；`submit_planned()` 或原来源提交入口使用选定的 options。应用继续提供状态、预算、取消、验证等级和可复用程序包。

直接提交的 period=4 验收见[输出共享](agent-output-alias-acceptance-r1486.md)。本轮三个新布局与该报告的三个数学模型重叠，不将二者相加为新模型数量。
