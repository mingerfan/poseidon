# 校准观察验收与执行次数

校准观察已完成：29 项控制检查、3 个独立观察案例（9 组输入）和 2 份已有真实 Agent 任务的观察（6 组输入）通过。

实际启动 6 次原生 worker：5 次成功，1 次因缺少只读依赖而导入失败；另有 1 次输入在启动前被拒绝。r1625 的“五个 worker”指成功执行次数。原失败记录及报告绑定保留。

本批 API、编译和密态调用均为 0。当前接口只统计原始模块输入，不拟合近似或认证完整模型精度。
