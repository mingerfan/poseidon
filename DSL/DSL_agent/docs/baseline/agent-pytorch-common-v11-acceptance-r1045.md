# PyTorch v11 接入验收

本批完成可信本地 PyTorch v11 的生产接入，沿用应用任务、预算、取消和来源包接口。Poseidon 密态验收尚未运行。

## 输入范围

| 调用 | 范围 |
|---|---|
| 加减 | 静态、有限的公开 `alpha`，公开常量或张量，以及加密张量组合 |
| Dropout | eval 模式下的模块、functional 和 spatial 调用 |
| 融合 Attention | 静态 SDPA，支持投影及中间表达式产生的 Q/K/V |
| Attention mask | 公开布尔、有限加性及因果 mask；显式近似配置 |

只有明确选择 `poseidon-trusted-pytorch-v11` 才启用新规则。旧 v1–v10、默认策略及用户层接口保持兼容。图中的近似计算与原函数分别比较。
