移除新精度控制器收集结果时的重复程序查询。程序包等级在提交时绑定，每次查询仍从当前程序结果核对；输出阶段还检查新读取的元数据。原数值控制器、生成与程序包接口保持原代码。

## 验收

- 当前范围29个不同检查通过；113个未受影响的兼容检查保持有效，共142个不同检查，失败／错误／skip为0。
- 三例完成新绑定验收。复用48组旧结果，只新增3组尾片计算；共6片、51组、136个输出值。
- 三个原生参考worker实际执行。API、编译、密态调用为0。
- 原数据集指标、候选源码、程序包与旧记录保持。新控制器计划建立新绑定，旧回执保留原来源和哈希。
- 检查覆盖等级冲突、输出阶段元数据漂移、重复查询次数及仅补算未完成片。

## 查询耗时

同一矩阵数据集的终态查询，在独立cProfile记录中从22.095秒降至12.589秒，减少约43%。程序结果查询从2次降至1次，source_closure调用从66次降至38次。这里只测量一次查询；未据此宣称10000条实际模型评测的吞吐。

本批三例共203.95秒，新产物417,792字节；处于1200秒／128MiB范围。与上一批的455秒不能直接作速度比较，因为本批复用了首片，并只计算尾片。

内容哈希、来源、包绑定、等级、dtype、形状、调用额度、取消和期限检查保持。没有按mtime信任文件，也没有跳过源码或二进制验证。
