# 来源规范化真实 Agent 测试

51 个 v23/v24 来源已完成当前隔离捕获与独立参考核验，按精确公开请求分成 26 组。本批实际生成26个代表请求；其余25个来源另行原样回放，不计为新的Agent生成。

范围：公开张量的 reshape、permute、slice、bool转换、别名、命名输出，以及 float32、float64、int32、int64、bool 的公开 dtype 转换与组合。模型、权重、reference、P4/w45及SDK保持不变。

DeepSeek deepseek-flash/high/stream，explicit-v13。每例最多3轮修复、每轮最多3次传输重试；全批最多104次生成、416次HTTP、104次编译、156次密态调用。API及密态串行，编译2、链接1；单次1200秒、384000tokens，每例4小时、全批12小时，native4GiB/CPU150秒，新增产物4GiB、全局32GiB、余量4GiB。无明确货币上限，超时重试可能重复计费。

外发公开图、权重或描述符、布局、DSL规则和受控反馈；私有测试、reference、凭据及原候选答案不进入请求。每个成功案例检查数值验收、程序包重载、三组新输入、一组重复输入和缓存。

使用现有的用户计划内测试总授权。安装、下载、后端、参数、网络和Git操作的权限保持原边界。

源码、请求、来源与预算见同名JSON；准备时限及公共状态ledger字段引起的开发启动问题和日志保留，尚未发生付费调用。
