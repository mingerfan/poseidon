# PyTorch 源码包准备层

源码包准备和快照接口已完成。当前应用／CLI仍使用v28平铺源码入口；多文件包的捕获与执行尚未接入。

## 实现

`pytorch_source_package.py` 接收显式文件清单、SHA-256和工厂入口。支持普通模块、含`__init__.py`的常规包、嵌套包、空初始化文件及相对导入声明。保留源码原始字节和模块路径，工厂入口使用`package.module.factory`。

`prepare`检查文件、哈希和静态导入；`snapshot`写入新目录；`read_snapshot`重新核对可信绑定和全部文件。快照完成记录最后写入。错误使用稳定原因与相对源码位置。

上限维持8个文件／64KiB；路径最多8层，AST合计最多32,768个节点。命名空间包待单独接入。
