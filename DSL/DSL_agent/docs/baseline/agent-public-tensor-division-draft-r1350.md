# 公开张量除法开发版

ARM Ubuntu `/home/lhohy/Code/Poseidon`，分支 `lhy-agent-dsl`。

## 实现范围

开发版将 `x / self.std` 中已声明的公开 float64 张量转换为逐项倒数乘法，覆盖向量、通道广播和密集权重；保留原图、原权重及来源映射。倒数由可信代码计算，公开权重和派生系数分别绑定哈希，外部校验要求原图身份。

沿用现有资源配置。除数必须有限且非零，除数及倒数绝对值均不超过 1024。加密除数、未声明或经额外计算的除数、非法广播及原地扩张返回拒绝。

三个密态案例分别为向量除数、通道广播除数、双输入与快照多输出。它们使用人工准备的等价图和规则候选。每份程序包重新加载后执行四组新输入，并与独立实现的原始除法逐项比较；复用阶段生成和编译调用均为 0。执行器只使用评估密钥。

首轮 46 项检查中有 24 个错误，原因是 Torch 2.0.1 的 FX 复制丢失输出节点元数据。补齐原始不可变类型信息后通过完整投影检查；原错误、快照和后续绑定分别保留。当前 52 项已包含后续新增的六项原图身份拒绝测试。
