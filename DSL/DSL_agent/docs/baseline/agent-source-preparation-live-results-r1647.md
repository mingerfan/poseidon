## 失败案例

rsqrt_mean 的四次生成均有原始响应和独立验收记录。首轮创建了契约禁止的数值数组；后三轮通过真实编译和密态执行，随后数值比较失败。第二轮迭代使用原均值而未使用已经计算的仿射分母；第三、四轮的掩码支持选错归约组，最后一轮还重复缩放均值。根据源码数据流，这是候选计算／槽位映射错误，不能认定为编译器或 CKKS 精度问题。

原失败保留，不改写为通过。下一批仅对原模型复用现有 explicit-v19 生成指导，重新冻结请求；不会向模型发送人工 DSL 或私有 reference。
