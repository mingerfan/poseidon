## 结论与口径

- 模型集交付及离线工程验收已复核完成。
- 自由生成与定向生成的原定任务均已有独立审计终态；失败和 provider 故障是评测结果，不能计为通过。
- Agent 尚未获得全部语义分区的成功覆盖，不能汇报为“所有 DSL 都能稳定生成成功”。
- 三个 bootstrap 语义分区保持后端阻塞；本阶段不实现真实 bootstrap、不切换 GPU/HEaaN。
- 历史源码、请求与配置分别保留。没有把多个版本择优拼成一个当前版本成功率。

上述第二项的“完成评测”指执行并报告结果，不等于每项都通过。离线正例证明契约与后端的有限语义能力；Agent 结果用于测量生成能力，不能互相替代。

公开权重、静态形状、纯推理；旧 schema 1–5 保留。统一图支持不同形状多输入、分叉、共享值、残差、多输出和分块布局。
请求准备不要求确定性 DSL 基线先成功。构造要求属于任务元数据，不改变数学模型。
