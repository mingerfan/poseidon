# 命名输出共享验收

`poseidon-model-graph-v2` 可显式选择 `exact-values-v1`：多个名称引用同一图值时，共享该值的密文输出块，解码后仍按原名称、shape、次序和嵌套结构返回。逻辑输出元素按所有名称计数，物理输出按共享后的块数计数。

四个名称都返回 20 元素的同一结果，period=4 时，输出块从 20 个降为 5 个。原输入输出容量、尾块规则和密钥要求保持。不同图值继续分别绑定。

## 实现

应用选项为 `output_binding_policy="exact-values-v1"`；CLI 使用 `--output-binding exact-values-v1`。`explicit-v15` 提供相应生成与修复指导。

布局记录逻辑输出、首个物理输出及别名关系；请求核验从实际模型重新计算。共享的 reference 准备入口供 CLI、应用验收和历史程序包重放使用。未选择此选项的行为和请求哈希保持：9 份旧请求按原字节重建。

本轮修改限于 Agent、验证适配器、测试和文档。容量 ABI v2/v3/v4、PyTorch 默认 v18／latest v34、Poseidon、CKKS Runtime、Dacapo、参数和数值门限保持。

## 范围与后续

本轮真实执行为 ARM Poseidon CPU、period=4。其他已配置周期仅有布局／控制检查；x86 密态执行、最高 rank 与容量、全部算子和别名组合仍待相应验收。共享仅依据同一图值引用，不进行任意表达式等价推断。
