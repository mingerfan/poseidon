## 实施

增加 `offline_expression_acceptance_v1`，按 r1286 原冻结范围调用现有资格验证、
程序包导出和只读重载。入口不写批准记录；各内部阶段均核验独立人类批准、
原提案、候选、模型、公开权重、源码及控制文件。批次开始后固定截止时间，
一次性结果目录和独占尝试记录阻止重复启动。

核对 SDK 的编译器、frontend、Poseidon 执行器、库、模数配置、OperatorSpec、
源码及 CMakeCache 身份；预期值来自保留的原失败验收记录。只比较文件身份，
没有调用编译器或库执行计算。

实际 Nix worker 复用原纯环境，候选仍使用既有独立沙箱；历史结果逐项只读挂载，
项目 .env 和 API key 不进入执行环境。资格验收保持数值等级与原四组输入，
不运行额外样本或缓存执行。失败保留原记录，不自动重试或提高额度。
