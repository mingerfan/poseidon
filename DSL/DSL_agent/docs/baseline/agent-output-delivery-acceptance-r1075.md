## 改动

新增 `model_output_contract.py`、`task_output_adapter.py` 及对应测试，复用现有 Application。支持命名张量、标量恢复、tuple/list、字符串键字典及静态 None；每次执行沿用 1–16 组样本边界。宿主显式选择适配器并保留可信收据绑定。

收据重载核对原任务、缓存来源、请求、模型、源码/来源、程序包、等级和当前实现。整数/布尔类型混淆及等值浮点元数据拒绝；已完成任务的旧状态和包保持。原编译或数值等级不因输出恢复改变。

初次 r1070 的 `test_structure_depth_boundary` 错误、45 项原结果及源码保留。JSON 结构深度按字典边的三层表示和固定交付封装推导；逻辑结构上限仍为 32。r1071/r1072 源码与结果另存，最终 r1073/r1074 建立新绑定。
