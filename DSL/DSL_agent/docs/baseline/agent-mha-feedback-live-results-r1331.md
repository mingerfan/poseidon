- 候选的明文逐槽计算与模型 reference 最大差异 **0.0023141187**，同样 40／64 项失败。
- 真实密态结果与候选自身逐槽计算最大差异 **1.38384e-7**，64 项均在门限内。
- `G0/G1` 对各 head 的点积取槽不一致，跨行／跨 head 混合；按同一候选投影值计算的正确分头点积与现有槽位拼接有 24 项差异。
