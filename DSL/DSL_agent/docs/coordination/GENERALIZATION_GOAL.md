# Goal A：通用模型到 Poseidon DSL 组件

建议目标文本：在 lhy-generalization 的独立 Ubuntu 工作目录中，基于同一已验证集成提交，将现有 Agent 完善为通用静态推理模型转换组件；完成模型接入、注册分解、通用算子、权重与布局容量、近似精度和有界任务控制，并用独立参考、真实 Poseidon 后端及真实 Agent 验收；通过稳定接口供整模型线使用。

## 目标

正常应用流程：提交模型与要求 → 能力/资源检查 → 上下文准备 → DSL 生成 → 自动验证/预算内修复 → 已验证程序包或明确终态。
Agent 用于模型转换和部署准备，重复推理复用程序包。开发探针、Benchmark 和人工诊断保持独立。

## 里程碑

| 编号 | 交付 | 完成条件 |
|---|---|---|
| A0 | 新目录、新后端身份和全局控制层 | 旧 CLI/schema/hash 兼容；两工作目录的共享预算/锁可审计；最新 Runtime 来源与实际 SDK 对齐；重复候选/失败、取消、恢复和反馈策略参与决策 |
| A1 | 通用接入 | JSON、受限源码和可信 PyTorch 统一模型包；工厂参数/子模块/权重/dtype/静态 shape/结构化输入输出支持；至少 6 个跨类别模型独立参考及真实后端通过 |
| A2 | 注册、分解与高阶算子 | 注册类型、shape、属性、参考、分解、近似、后端依赖；递归环、膨胀、来源、广播和组合检查；每个新增可执行分区 3 个上下文 |
| A3 | 权重、布局和容量 | 万参数请求不完整内联到提示；至少 8 个真实后端模型，至少一半用非重复随机权重；跨块卷积/归约/拼接/残差/尾块/解码真正执行 |
| A4 | 近似质量与应用要求 | 原函数、声明近似、分解和 CKKS 分项；逐节点/模块/默认 selector 及冲突拒绝；明确指标未达标返回终态；冻结 reference 和已声明近似不被 DSL 修复改变 |
| A5 | 后端与程序包 | 复用 B 认证的 Runtime/Poseidon 公共能力接入 bootstrap/CUDA；CPU 与 CUDA 身份独立；至少 3 包导出、重载、新输入、重复执行和缓存验证 |
| A6 | 通用性 Agent 评测 | 多模型族、不同源码写法、未见无环组合；自由与定向分别记录；首次/修复/编译/数值/构造/预算/后端阻塞分开汇总 |

第一版算子范围保留原计划：线性与矩阵运算、Conv1d/2d（含组/深度卷积）、归一化、激活和 exp/倒数/sqrt/rsqrt、池化和归约、张量组合、Softmax/LogSoftmax/Attention/MHA/RoPE/公开 mask/固定 KV，以及推理残差、共享值、多输入输出和 eval Dropout。
max/min、ReLU 等非多项式行为须使用明确近似方法、区间和参数。动态 shape、训练、加密条件分支和加密索引保持明确拒绝。公开 DSL helper 与构造语义继续用现有清单逐项映射；bootstrap 项保留真实状态。

容量目标为 general rank 1–32；最高现有配置 I/O 各 4096、单中间张量 65536、原图 1024、分解图 4096、权重 1000000，另受算子、物理密文、源码和资源限制。旧小型配置保持原边界。接入上限不能替代执行验收。

## 执行与完成

优先复用历史真实 Agent 源和已验证 package，只验新增/受影响范围。输入或提示扩展仍要真实 Agent 验收；后端兼容重放不额外记为新生成。
源码冻结和新绑定先于运行。数值门限为 1e-5 + 1e-4*abs(reference)，独立数学差分为 1e-12 + 1e-12*abs(reference)。
遵守 PARALLEL_DEVELOPMENT.md 的所有权、资源和权限。B 的整模型数据、校准、精度和最终报告不在本线重复实现。
不为“通用”承诺任意 Python、无限输入或所有函数精度。可执行范围须有真实证据；受阻范围保留原例与失败层。
完成须逐项核验 A0–A6、公开版本化能力清单、组件接口和程序包。预算到期或其他后端缺口不是完成条件。
