## 自举与边界

- 输入 levels：`[5, 5]`；输出 levels：`[1, 1, 1, 1, 1, 2, 2]`。
- 自举转换：L1→L5 共74次。
- 自举为真实 CPU 实现，输出 scale43；不是解密再加密。精确 Value ID、每次输入输出 level 见 evidence/two-layer-audit.json 的 execution.boot_transitions。
- 完整模型各 Value 的 level 取决于编译后的共享、调度和 rescale；不把整个 RMSNorm/Attention 概括成一个固定 level。
