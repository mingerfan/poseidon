两次运行密钥、执行时间点和运算计划不同；这是已完成样本的观察结果，不是重复采样的性能保证，也不能视为纯线程加速比。
CPU累计秒是所有执行线程消耗时间的总和，墙钟Runtime是用户实际等待时间。自举次数减少不保证墙钟按同比例减少；单次Boot耗时变化应单列，没有配对负载/频率/逐Boot CPU测量时，不将变化归因于某个优化或服务器其他用户。

全保留图系数统计每个独立 Value，包括重编码明文；没有实际启用全保留运行。它不含密钥、自举内部历史临时对象、编码器工作区及分配器。释放图峰值是计划活跃载荷；真实 RSS 包含运行库、密钥与工作区，三者不能混用或相加。
