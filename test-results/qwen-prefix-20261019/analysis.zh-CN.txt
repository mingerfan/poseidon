四 V100 Qwen 200 万条执行记录复测结论

新版和旧版均已完成执行。新版执行段 866.813 秒（14 分 26.813 秒），
旧版 2004.265 秒（33 分 24.265 秒）；本次单次配对速度比为 2.3122，
执行耗时减少 56.75%。四卡时间加权 GPU busy 平均值从 4.327% 增至 10.107%。
包含初始化、密钥生成及输出校验的整个进程分别为 919.035 秒和 2053.934 秒。
这比较 previous Runtime Auto/8 与 updated Runtime Auto/128，二者共享当前 GPU 后端；
不是对全部历史修改的回滚对照，也不能把提升全部归给某一项修改。

为何明显加快
旧版 143955 次明文准备中，45929 次走 CPU 编码，98026 次走 GPU；
新版 143955 次全部走 GPU，CPU 编码变为 0 次。
旧版 CPU 编码跨线程累计 1024.196 秒，同时产生 80317317120 字节的明文 H2D；
新版这两项都为 0。普通 Host cipher 与 CPU 明文上传合计从 85.159 GiB 降到 10.358 GiB。
编码提交累计耗时从 1276.563 秒降到 316.561 秒。
这支持“避免 CPU 编码路径和对应明文上传，改善准备/提交重叠”是重要因素。
这些累计时间可跨线程重叠，不能相加或直接除以墙钟来分摊加速贡献。
本次没有隔离预取窗口、工作线程、GPU-first Auto 的单独贡献。

为何利用率仍只有约 10%
新版 bundle 读取累计 24.185 秒，GPU Encode 实际事件时间累计 35.526 秒；
CPU Prepare 为 0。当前明文 ledger 峰值最大约 0.529 GiB，低于每卡 15.5 GiB 明文配额。
各卡 foreground 与 plaintext 的峰值之和也低于对应 allocator_graph_capacity，
共享 host、pinned、raw 峰值均低于配置容量。这里不能归因为水位容量耗尽。
但是未触及容量不等于按需准备、等待和调度没有成本；本次也没有测相同图的全驻留对照。

其余可见成本包括：1692 次 secret-key-assisted Host decrypt-reencrypt refresh，
新版累计 246.181 秒，旧版 249.255 秒，基本没有减少；它不是 native bootstrap。
执行图还有 345950 条 GPU 间传输，按计划中 level、components、N 和 uint32 数据布局，
逻辑有效载荷合计 1052340387840 字节（0.957 TiB）。服务器拓扑显示卡间为 PIX，
未显示 NVLink 连接。这个逻辑字节数不是硬件计数器测出的实际 PCIe 流量。
新版 communication post API 累计 617.414 秒，旧版 315.612 秒；增加可能包含更高并发下的
排队/驱动争用，不能据此断言硬件传输本身变慢。需要进一步隔离通信与提交路径才能定位。
source-inspection.txt 中的多设备 cudaSetDevice 线索尚未验证，不能当作已证明根因。

数值验证没有通过
参考和容差没有放宽：atol=0.001，rtol=0.0001，每个输出检查全部 8192 个复数槽。
旧版通过 10/16，新版通过 9/16；两组都没有非有限值或不合格零尾，主要失败集中在 K。
旧版最大实部绝对误差 0.005455337，最大虚部 0.018551955；
新版分别为 0.018235971 和 0.062724441，实部与虚部失败槽也更多。
新版误差更大必须单独定位；不能因为旧版也失败就认定数值没有回归，
也不能用这一个同时改变调度、编码路径、窗口的配对实验判定是哪项导致。
因此性能目标得到可测提升，但本轮数值校验失败，不代表完整 Qwen 正确运行。

全加载对照的边界
这段图所有 Prepare 输出缓冲若不释放、也不做内容去重，每卡合计约 57.9～59.6 GiB，
超过单卡 32 GiB。此数是所有输出缓冲之和，不是同时存活峰值，也不是原始权重大小。
所以对这段原样图不能直接把全部已编码明文永久放在各卡上；需要另定义分层驻留或去重方案。
本次测量不能替代同一可驻留工作集上的“全加载与水位加载”对照。

测量质量
有效数据仅 runs-nvml/：常驻 NVML 每 2 秒采样一次；每轮约 7～8 毫秒，
两组均无遥测异常，无其他 GPU 计算进程。原始频繁重启 nvidia-smi 的轮次已排除。
原始 Runtime 头文件和共享库在完成后复核哈希，均未变化。
完成后四卡显存占用归零、volatile uncorrectable ECC 均为 0，本实验进程已退出。
每种组合仅一次，先新版后旧版，未固定 OS 缓存、CPU 亲和性、GPU 时钟。
计时、曲线与全部汇总见 results.zh-CN.txt、gpu-utilization.png 和 summary.json；
原始报告保留于 runs-nvml/，静态算子/通信统计见 prefix-operations.json。
